# Фронтенд и бэкенд разработка — дополнительные контрольные задания

| Папка | Задание | Технологии |
|---|---|---|
| [`task1-crud`](task1-crud) | №1 — CRUD + React + Swagger | Node.js, Express, React, Swagger UI |
| [`task2-auth`](task2-auth) | №2 — Регистрация, вход, JWT, роли | Express, bcrypt, JWT, React |
| [`task3-pwa`](task3-pwa) | №3 — Заметки как PWA | HTML/CSS/JS, Service Worker, Manifest |
| [`task4-docker`](task4-docker) | №4 — Товары + БД + кэш + Docker | Express, PostgreSQL, Redis, Docker Compose |
| [`task5-graphql`](task5-graphql) | №5 — GraphQL + брокер сообщений | Apollo Server, RabbitMQ |

В каждой папке есть:
- `README.md` — как запустить и что показать преподавателю;
- `ЗАЩИТА.md` — шпаргалка: главные понятия и ответы на вероятные вопросы.

## Что нужно установить

1. **Node.js** LTS (22.x): https://nodejs.org — проверка: `node -v`
2. **Git**: https://git-scm.com — проверка: `git --version`
3. **Docker Desktop** (для заданий 4 и 5): https://www.docker.com/products/docker-desktop — проверка: `docker -v`
4. Редактор кода — **VS Code**.
