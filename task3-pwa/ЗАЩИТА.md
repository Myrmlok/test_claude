# Шпаргалка к защите — задание №3

## Главное в двух словах
**PWA** (Progressive Web App) — сайт, который ведёт себя как приложение: работает без интернета и устанавливается на компьютер или телефон.
Для этого нужны три вещи:
1. **Service Worker** (`sw.js`) — кэширует файлы и отдаёт их без сети;
2. **Web App Manifest** (`manifest.json`) — описание приложения для установки;
3. **HTTPS** или **localhost**.

## Вопросы и ответы

**Что такое Service Worker?**
JavaScript-файл, который браузер запускает в фоне, отдельно от страницы. Он работает как посредник между страницей и сетью: перехватывает запросы и может отвечать из кэша. Доступа к DOM (элементам страницы) у него нет.

**Как он подключается?**
В `app.js`: `navigator.serviceWorker.register('sw.js')`.

**Какие события обрабатывает наш Service Worker?**
- `install` — при установке открываем кэш и кладём туда все файлы приложения (`cache.addAll(ASSETS)`);
- `activate` — удаляем старые версии кэша;
- `fetch` — перехватываем каждый запрос: если файл есть в кэше, отдаём его, иначе идём в сеть.

**Какая стратегия кэширования используется?**
**Cache First** («сначала кэш»): сначала ищем в кэше, если нет — загружаем из сети. Поэтому приложение открывается без интернета.

**Что такое Cache Storage?**
Хранилище браузера для пар «запрос → ответ». Работаем с ним через `caches.open(...)`. Видно в DevTools → Application → Cache Storage.

**Что лежит в кэше?**
Статические файлы: `index.html`, `style.css`, `app.js`, `manifest.json`, иконки (массив `ASSETS` в `sw.js`).

**Где хранятся заметки?**
В `localStorage` — хранилище браузера «ключ → строка». Массив заметок превращаем в строку через `JSON.stringify` и обратно через `JSON.parse`. localStorage не зависит от сети, поэтому заметки видны и добавляются офлайн.

**Чем Cache Storage отличается от localStorage?**
Cache Storage хранит файлы приложения (HTML, CSS, JS) для Service Worker. localStorage хранит наши данные — заметки.

**Как приложение работает без сети?**
1. При первом открытии Service Worker сохраняет файлы в кэш.
2. Без сети браузер запрашивает страницу → Service Worker перехватывает запрос и отдаёт файлы из кэша.
3. Заметки берутся из localStorage, новые туда же и сохраняются.

**Что такое Web App Manifest и что в нём?**
JSON-файл с описанием приложения для установки:
- `name` — полное название, `short_name` — короткое (под иконкой);
- `start_url` — какая страница открывается при запуске;
- `display: standalone` — открываться в отдельном окне без адресной строки;
- `theme_color` — цвет интерфейса окна, `background_color` — цвет экрана загрузки;
- `icons` — иконки (192×192 и 512×512).

Подключается в `index.html`: `<link rel="manifest" href="manifest.json">`.

**Что нужно, чтобы приложение можно было установить?**
Manifest с name, иконками 192 и 512, start_url и display; зарегистрированный Service Worker; HTTPS или localhost.

**Зачем `skipWaiting` и `clients.claim`?**
Чтобы новая версия Service Worker сразу начинала работать, а не ждала закрытия всех вкладок.

**Как обновить кэш после изменения файлов?**
Поменять имя кэша, например на `notes-cache-v2`. Новый Service Worker создаст новый кэш, а в `activate` удалит старый.
