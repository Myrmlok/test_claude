# Задание №1 — CRUD-приложение «Библиотека»

Клиент-серверное приложение: сервер на **Node.js + Express** (REST API), клиент на **React**.
Сущность — **Книга (Book)**: `id`, `title` (название), `author` (автор), `year` (год издания).

## Структура

```
task1-crud/
├── server/
│   ├── index.js     — сервер Express и все маршруты API
│   └── swagger.js   — описание API для Swagger (OpenAPI 3.0)
└── client/
    └── src/
        ├── App.jsx  — интерфейс: таблица книг и форма
        └── api.js   — функции запросов к серверу (fetch)
```

## Запуск

Нужно **два терминала**.

**Терминал 1 — сервер:**
```bash
cd task1-crud/server
npm install
npm start
```
Сервер: http://localhost:3000, документация: http://localhost:3000/api-docs

**Терминал 2 — клиент:**
```bash
cd task1-crud/client
npm install
npm run dev
```
Открыть http://localhost:5173

## REST API

| Метод | Адрес | Что делает |
|---|---|---|
| GET | `/api/books` | список книг |
| GET | `/api/books/:id` | книга по id |
| POST | `/api/books` | добавить книгу |
| PATCH | `/api/books/:id` | изменить книгу |
| DELETE | `/api/books/:id` | удалить книгу |

## Что показать на защите

1. Запустить сервер и клиент (оба терминала).
2. Открыть http://localhost:3000/api/books — в браузере виден JSON со списком книг.
3. Открыть http://localhost:5173 — список книг в интерфейсе.
4. **Добавить** книгу через форму → она появилась в таблице.
5. **Изменить** книгу (кнопка «Изменить» → поменять поле → «Сохранить»).
6. **Удалить** книгу.
7. Открыть **Swagger UI**: http://localhost:3000/api-docs → раскрыть `GET /api/books` → **Try it out** → **Execute**. Так же можно показать остальные операции.

> Данные хранятся в памяти сервера, поэтому после перезапуска сервера список возвращается к исходному.
