# Шпаргалка к защите — задание №1

## Главное в двух словах
Есть **сервер** (Express), который хранит книги и отдаёт их по **REST API** в формате **JSON**.
Есть **клиент** (React) — страница в браузере, которая отправляет запросы серверу через `fetch` и показывает результат.
**Swagger** — автоматическая страница с документацией API, где можно отправлять запросы прямо из браузера.

## Вопросы и ответы

**Что такое REST API?**
Способ общения клиента и сервера через HTTP. Каждый ресурс имеет адрес (`/api/books`), а действие задаётся HTTP-методом: GET — получить, POST — создать, PATCH — изменить, DELETE — удалить. Данные передаются в JSON.

**Что такое CRUD?**
Create, Read, Update, Delete — создание, чтение, изменение, удаление. У нас это POST, GET, PATCH, DELETE.

**Что такое Express?**
Библиотека для Node.js, чтобы быстро писать веб-сервер: `app.get(адрес, функция)` — «когда придёт GET-запрос на этот адрес, выполни функцию».

**Что такое `req` и `res`?**
`req` (request) — входящий запрос: параметры адреса (`req.params.id`), тело (`req.body`). `res` (response) — ответ: `res.json(...)` отправляет JSON, `res.status(404)` задаёт код ответа.

**Что значит `:id` в адресе `/api/books/:id`?**
Параметр маршрута. Для запроса `/api/books/2` значение `req.params.id` будет `"2"`.

**Зачем `app.use(express.json())`?**
Чтобы сервер понимал JSON в теле запроса и складывал его в `req.body`.

**Зачем `cors()`?**
Клиент работает на порту 5173, сервер — на 3000. Браузер по умолчанию блокирует запросы на «чужой» адрес. CORS разрешает такие запросы.

**Какие коды ответа используются?**
200 — ОК, 201 — создано, 204 — удалено (тело пустое), 400 — ошибка в данных запроса, 404 — не найдено.

**Чем PATCH отличается от PUT?**
PATCH меняет только переданные поля, PUT заменяет объект целиком.

**Где хранятся данные?**
В массиве `books` в памяти сервера. После перезапуска изменения пропадают (база данных в этом задании не требовалась).

**Что такое React-компонент?**
Функция, которая возвращает разметку (JSX). У нас главный компонент — `App`.

**Что такое `useState`?**
Хранилище данных компонента. При изменении значения (`setBooks(...)`) React заново отрисовывает страницу.

**Что такое `useEffect`?**
Код, который выполняется после отрисовки. С пустым массивом `[]` — один раз при открытии страницы. У нас он загружает список книг.

**Как клиент общается с сервером?**
Через `fetch` в файле `api.js`. Например, `createBook` отправляет POST на `/api/books` с JSON в теле.

**Что такое Swagger / OpenAPI?**
OpenAPI — стандарт описания API (адреса, методы, поля, ответы). Swagger UI — страница, которая показывает это описание и позволяет отправлять запросы. Описание у нас в `server/swagger.js`, подключено по адресу `/api-docs`.

**Что изменили по сравнению с исходным проектом?**
Вместо сущности `User` сделали `Book` с полями `title`, `author`, `year`. Переделали маршруты сервера, форму и таблицу на клиенте, описали API в Swagger.
